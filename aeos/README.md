# AEOS v0.2 — Core Instructions

Entry point: root `AGENTS.md`; optional adapters `CLAUDE.md` and `GEMINI.md`.

- `CORE_POLICY.md` — permissions, safety, truth, evidence, verification, Git Policy A.
- `BOOTSTRAP.md` — **AEOS INIT** creates PROJECT.md and STATE.md after ideation, no implementation.
- `PLAYBOOKS.md` — DISCOVER, INIT, PLAN, BUILD, DEBUG, REVIEW, RECOVER, RELEASE.
- `QUALITY_PROFILES.md` — category-specific evidence.
- `RECORDS_AND_HANDOFFS.md` — source-of-truth and handoffs.
- `templates/` — optional source templates (do not copy all into project).
- `examples/` — sample first message and YCT Alert case.

Updates to AEOS itself should be reviewed against project-specific rules. **Do not auto-sync or overwrite this vendored copy in existing projects.** This folder is safe to version with the project once the human approves Git commits.
