# Background and attribution

AEOS is a user-designed working methodology informed by the YCT Map, YCEP and XcelerateAI experiences, the YCT Alert builder blueprint and general engineering-agent practices. The v0.2 change adopts a drop-in repository root and a documentation-only initialization phase. No affiliation with any AI provider is claimed.

Useful source locations for readers wishing to verify current platform behavior:
- OpenAI Codex instruction files: https://developers.openai.com/codex/guides/agents-md/
- Anthropic Claude Code memory files: https://code.claude.com/docs/en/memory
- Gemini CLI configuration: https://geminicli.com/docs/cli/gemini-md/
- GitHub Copilot repository instructions: https://docs.github.com/en/copilot/how-tos/configure-custom-instructions/add-repository-instructions
- OWASP Agentic AI Security: https://genai.owasp.org/

These links are reference pointers, not independently audited assertions about the exact behavior of a future agent runtime.
